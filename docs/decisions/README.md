# Architecture Decision Records (ADRs)

This directory is the **audit trail** for the project — the single most important artifact for
reviewing AI-built code (ENGINEERING_STANDARDS §4). Each ADR is a numbered, **immutable-once-accepted**
record of one non-trivial decision: *problem → options → decision → consequences*. It turns "why did
the agent build it this way?" into a reviewable trail.

Format: **[MADR](https://adr.github.io/madr/)**. Start from [`0000-template.md`](0000-template.md).

## Rules

- **One ADR per non-trivial decision.** `NNNN-kebab-title.md`.
- **Immutable once accepted.** To change a decision, write a **new** ADR that supersedes the old one
  (update the old one's `status:` to `superseded by ADR-XXXX`); never rewrite history.
- **Cite the source.** Every ADR links the relevant `DESIGN.md` / `DEVELOPMENT_PLAN.md` /
  `RESEARCH_SURVEY.md` / `ECOSYSTEM_AND_COUPLING.md` sections.
- **Number BLOCKS, not `ls`-then-guess (ADR 0029).** With parallel work lines (ADR 0028) two sessions that
  both pick "the next number" collide. Take the next free number **from your line's block** and add your row
  to **your line's subsection** below, so two lines never touch the same lines of this file:

  | Block | Owner |
  |---|---|
  | 0001–0029 | shared history + the cross-cutting/workflow decisions (integrator) — **EXHAUSTED**, use 0090–0099 |
  | 0030–0049 | line S — Component-S science — **EXHAUSTED** by ADR 0049, use **0100–0119** |
  | **0050–0069** | **line M** — multi-cell coupled S+F+E |
  | **0070–0079** | **line E** — Component E vs observations |
  | **0080–0089** | **line O** — online coupling (Terrarium / SpeedyWeather) |
  | **0090–0099** | **integrator / cross-cutting** — the continuation of 0001–0029, opened by ADR 0090 |
  | **0100–0119** | **line S — TIER 2**, opened by ADR 0100 (the tier-1 block 0030–0049 is exhausted) |
  | 0120–0139 | line M — tier 2 (unopened) |
  | 0140–0149 | line E — tier 2 (unopened) |
  | 0150–0159 | line O — tier 2 (unopened) |
  | 0160–0169 | integrator / cross-cutting — tier 2 (unopened) |

  **Tier 2 exists because a block CAN run out** (line S's did, at ADR 0049, mid-milestone). Each line's tier-2
  block is pre-allocated so an exhausted line never has to negotiate a range before it can record a decision,
  and so two lines exhausting their blocks in the same week cannot collide. Do **not** renumber a tier-1 ADR
  and do **not** borrow another line's tier-2 block.
